# FitnessSubscriptions

Модель предметной области «Тарифы и абонементы»
Учебный проект: библиотека классов + консольная демонстрация + тесты.

## Что внутри

- `Tariff` — перечисление тарифов: разовый, месячный, годовой, студенческий.
  Каждая константа сама считает стоимость через `priceFor(Period)`.
- `Subscription` — абонемент: тариф, дата начала, срок, заморозка, история операций.
- `Client` — клиент с набором абонементов.
- `SubscriptionException` — своё исключение для некорректных операций.

## Операции

- Покупка
- Продление (`extend`)
- Заморозка на N дней со сдвигом даты окончания (`freeze`)
- Разморозка (`unfreeze`)
- Проверка «действует ли на дату» (`isActiveOn`)
- Использование с проверкой на просрочку/заморозку (`use`)
